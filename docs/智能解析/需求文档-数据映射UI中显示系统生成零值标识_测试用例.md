## 测试用例

### 一、零值默认填充与 AI 映射

| 编号 | 测试用例名称 | 前置条件 | 测试步骤 | 预期结果 |
|---|---|---|---|---|
| TC-001 | 单月缺失自动填零并进入映射 | 上传文件，某源科目（如 "S&M Payroll"）在 3 月单元格为空，其余月份有值 | 完成数据提取与映射 | 3 月单元格被填为 0，该科目进入 AI 映射流程，不因 3 月缺失被放入 Unmapped |
| TC-002 | 多个空月度单元格全部填零 | 某源科目在 2 月、5 月、8 月单元格均为空 | 完成数据提取 | 2/5/8 月单元格均被赋值为 0，每个空单元格独立填零 |
| TC-003 | 反向：缺少科目名称进 Unmapped | 上传文件，某行无科目名称 | 完成数据提取与映射 | 该行被放入 Unmapped 区（因缺少科目名，非因月度缺失） |
| TC-004 | 反向：无法识别 year-month 进 Unmapped | 上传文件，某科目月份列无法被解析为有效 year-month | 完成数据提取与映射 | 该科目被放入 Unmapped 区 |
| TC-005 | 反向：无法识别科目类型进 Unmapped | 上传文件，某科目类型无法被识别 | 完成数据提取与映射 | 该科目被放入 Unmapped 区 |
| TC-006 | 仅缺月度数据不再进 Unmapped（行为对照） | 某科目名称、year-month、科目类型均合法，仅个别月份缺数据 | 完成数据提取与映射 | 该科目正常进入映射，不被放入 Unmapped，区别于旧"缺月即排除"行为 |
| TC-007 | 填零在映射前完成视图无空单元格 | 上传含缺失月度单元格的文件 | 进入 Data Mapping 映射视图查看 | 视图中所有月度单元格均已有数值（无空白），填零在进入视图前已完成 |

### 二、系统生成零值视觉标识

| 编号 | 测试用例名称 | 前置条件 | 测试步骤 | 预期结果 |
|---|---|---|---|---|
| TC-008 | 系统生成零值单元格显示视觉标识 | 某科目 3 月为系统填充的 0 | 进入映射视图查看 3 月单元格 | 该单元格显示数值 0，并附轻量化视觉标记（如小图标/特殊样式/浅色背景），区别于普通单元格 |
| TC-009 | 悬停显示 Tooltip 文案 | 同上，3 月为系统生成零值单元格 | 将鼠标悬停在该单元格的视觉标记上 | 显示 Tooltip，文案为 "No value extracted. Defaulted to 0."（或同义友好文案） |
| TC-010 | 显式源零值单元格无标识无 Tooltip | 某科目 4 月在源文档中本就显式为 0 | 查看 4 月单元格并悬停 | 该单元格显示 0 但**不显示**任何视觉标记，悬停无 Tooltip |


### 三、用户编辑行为

| 编号 | 测试用例名称 | 前置条件 | 测试步骤 | 预期结果 |
|---|---|---|---|---|
| TC-013 | 编辑系统零值输入新值后标识移除 | 某科目 3 月为系统生成零值（带标识） | 点击 3 月单元格，输入 100 并提交 | 单元格值变为 100，视觉标记与 Tooltip 永久移除 |
| TC-014 | 编辑后仍输入 0 视作手动输入不再加标识 | 某科目 3 月为系统生成零值（带标识） | 点击 3 月单元格，输入 0 并提交 | 单元格值仍为 0，但视作用户手动输入，视觉标记与 Tooltip 不再出现 |
| TC-015 | 编辑一个单元格不影响同行其他系统零值 | 某科目 2 月、5 月均为系统生成零值（均带标识） | 编辑 2 月单元格输入 50 并提交 | 2 月标识移除；5 月单元格不受影响，仍保留系统生成零值标识与 Tooltip |
| TC-016 | 标识永久移除不随刷新恢复 | 已编辑某科目 3 月单元格（标识已移除） | 刷新/重新进入映射视图查看 3 月单元格 | 3 月不再显示系统生成零值标识，标识永久移除不恢复 |
| TC-017 | 重新编辑回 0 仍不恢复系统标识 | 某单元格曾被手动编辑为 100 | 再次编辑该单元格改回 0 并提交 | 仍视作手动输入，不恢复系统生成零值标识 |
