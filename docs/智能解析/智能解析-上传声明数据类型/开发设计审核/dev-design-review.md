## 6. 已核对无问题

- **三端契约**：取值映射、返回码（422 / 200 + `success:false`）、uploadComplete 只校验 PENDING 行，均与代码一致。
- **触发入口**：类型写入入口覆盖 commitUpload、getUploadUrl（带 taskId）、replaceFile 三条；替换不能跨任务继承。
- **rag 行与财务行互不改写**：四个 rag 登记函数拒绝非 rag 行；读路径都是等值过滤；V030 编号未被占用，DB 上没有 CHECK 障碍。
- **新状态迁移**：UPLOADED → FILE_FAILED 在既有状态机"任意阶段 → FILE_FAILED"之内；前端没有"失败前必经 PROCESSING"的假设。
- **幂等与时序**：SQS 在 afterCommit 发送，重投幂等；并行路径取的是本文件的类型；报错日志不泄露敏感信息。
- **改动边界**：Stage 2.65 位置正确；删除的符号没有外部依赖；前端改动封闭在财务目录内。
