# 需求文档：Company Memory File Layer 1a 后端 — 聊天提取：竞争格局

**来源任务**：Company Memory File Layer 1a Backend - Chat Extraction: Competitive Landscape
**Asana 链接**：https://app.asana.com/1/1170332106480422/project/1202050347057533/task/1214953638826105
**适用模块**：AI Chatbot Layer 1a 后端 — 公司端聊天对话中竞争格局信息的实时增量提取
**类型**：后端与数据架构需求（**无用户可见 UI**）

---

## 一、背景与范围

本需求覆盖公司端聊天对话中**竞争格局（Competitive Landscape）信息**的**实时增量提取**到 Layer 1a 记忆文件。

理解一家公司**与谁竞争**、**如何差异化**，以及**竞争对手相对的优势与劣势**，能够为 AI 提供战略对话所需的关键上下文。

竞争信息**随对话自然累积**——创始人通常在以下场景中提到竞争对手：
- 讨论赢单或丢单时；
- 描述自身定位时；
- 谈到定价挑战时；
- 寻求关于竞争替换（competitive displacement）的建议时。

系统在以上场景中提取：
- **关键竞争对手的名称**；
- 创始人对**这些竞争对手相对自身产品的优劣势**的描述；
- 关于**竞争动态如何随时间变化**的任何上下文。

此外，**替代品威胁（substitution threats）**——客户可能考虑的、非直接竞争的替代方案——在被提及时也会被提取，作为一个**独立的、重要的竞争风险类别**。

### 关键定位约束
- 存储在记忆文件中的竞争信息**反映的是创始人的视角**，应被视作"创始人对竞争格局的看法"，**不是**客观的市场评估；
- 这个区分对未来 AI 在回复中如何**使用和呈现**这些信息**至关重要**。

---

## 二、功能描述

### 2.1 提取触发

- 提取为**实时增量**：在每次消息交换发生时即评估；
- 提取处理**异步运行**，**不阻塞**或延迟 AI 回复的交付。

### 2.2 竞争对手（Competitor）提取

#### 提取目标
- **正确识别并提取**创始人在对话中引用的**竞争对手名称**；
- 对**每个**被提及的竞争对手，提取所提供的相关上下文，包括：
  - 该竞争对手相对创始人产品的**竞争定位陈述**（competitive positioning statements）；
  - 示例："we win on ease of use but lose on enterprise feature depth"（我们在易用性上胜出，但在企业级功能深度上不及）；
- 提取关于**竞争动态及其随时间变化**的上下文，例如：
  - "a new well-funded competitor entered the market last quarter"（上季度有一个资金雄厚的新竞争者进入市场）。

### 2.3 替代品威胁（Substitution Threat）提取

- **正确识别并提取**被提到的**替代品威胁**——客户可能考虑的**非直接竞争**的替代方案；
- 示例："most of our prospects are currently using spreadsheets and internal tools"（我们大多数潜在客户目前使用电子表格和内部工具）；
- 替代品威胁**作为与直接竞争对手不同的独立类别**存储。

### 2.4 完整性与更新

- 当创始人提供与已有条目**矛盾或实质性改变**的新竞争信息时（例如 "we actually now win deals against Competitor X more often than we lose"），**更新**已有条目以反映当前理解；
- 竞争信息在存储与检索时**带有归因（attribution）**——明确标注为**反映创始人视角**。

### 2.5 性能与错误处理

- 提取尝试**失败时**记录日志，**不向用户暴露**错误；
- 即使单次提取失败，**Chatbot 继续正常运作**。

## 三、范围边界与跨需求约束

| 内容 | 归属 |
|---|---|
| 创始人提到的竞争对手名称 | **本需求** |
| 竞争对手优劣势 / 定位陈述 | **本需求** |
| 竞争动态随时间的变化 | **本需求** |
| 替代品威胁（非直接竞争） | **本需求**（独立类别） |
| 行业与监管背景（结构性外部环境） | Company Facts — Industry & Regulatory Context 需求 |
| Porter's Five Forces 框架（含 Threat of Substitutes 等五力） | Porter's Five Forces 提取需求（不在本需求） |
| 通用市场评估 / 客观市场判断 | 不存（仅存"创始人视角"，不冒充客观评估） |
