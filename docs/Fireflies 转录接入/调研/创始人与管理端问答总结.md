# 客户端管理端回答内容权限



## 一、创始人提问，AI 回答什么内容

**信息来源：** 仅从「创始人记忆 1a」+「创始人 Knowledge Base」+ 专家证词的匿名摘要中提取。所有内容为**去逐字化**处理。

**转录访问约束：** 只能看到**本人参加**的会议完整转录；未参加的即使与本公司相关，也只能通过 1a / Founder KB 的摘要感知。（待确认）

| 会议类型 | 创始人能得到的回答 |
|---|---|
| **GS → 创始人** | 会议摘要（记忆 1a + Founder KB 均写入） |
| **GS → 董事会/创始人（三方）** | 会议摘要（记忆 1a + Founder KB 均写入） |
| **GS → 有限合伙人 LP** | ❌ 无任何常规内容；如涉及专家证词，仅可看到**内容摘要 + 专长摘要**（融资 / 市场 / 估值倍数），**看不到发言者/组织等来源信息** |
| **GS 内部** | ❌ 无任何内容 |
| **GS → 战略伙伴/退出合伙人** | ❌ 无任何常规内容；如涉及专家证词，仅可看到**内容摘要 + 专长摘要**（商业采购行为、软件使用、倍数、买家行为、退出趋势），**无来源信息** |

---

## 二、管理端（Portfolio Group Manager / Super Admin）提问，AI 回答什么内容

**信息来源：** 「管理端记忆 1b」+「跨公司共享层 Cross-Company」+ 专家证词的**完整来源信息**（提供者、角色、组织、时间戳、专长标签）。

| 会议类型 | 管理端能得到的回答 |
|---|---|
| **GS → 创始人** | 会议摘要；跨公司层可获得**匿名摘要** |
| **GS → 董事会/创始人（三方）** | **退出准备（Exit-Readiness）/ 战略方面**的摘要——即资本运作、IPO/并购合规标准下的中长期战略规划；跨公司层附 **care flag** |
| **GS → 有限合伙人 LP** | **投资组合（基金）层面**的摘要；跨公司层仅提取**市场趋势**（外部宏观 + 可复用普适趋势，在途交易需隔离）；专家证词覆盖**融资 / 市场 / 估值倍数**，并显示完整来源 |
| **GS 内部** | 涉及**具体公司**的内容摘要；跨公司层输出**战略-决议闭环**（战略方向 → 议题 → 决策 → 行动项 → 责任人）与**全公司视角/全局观点** |
| **GS → 战略伙伴/退出合伙人** | 涉及**具体公司退出**的内容摘要；跨公司层输出**市场趋势、商业变现趋势、可移植趋势**，**在途交易信息全部隔离**；专家证词覆盖**商业采购行为、软件使用、倍数、买家行为、退出趋势**，并显示完整来源（提供者、角色/组织、时间戳、专长标签） |

---

## 三、核心差异一句话概括

- **创始人视角**：仅在会议明确面向自己（→ 创始人 / 三方董事会）时获得摘要；LP、GS 内部、战略伙伴类会议**默认不可见**；专家证词类内容**只见结论、不见来源**。
- **管理端视角**：**全会议类型均有可见路由**，覆盖具体公司层、基金组合层、跨公司趋势层，并掌握专家证词的**完整来源与元数据**，承担改判与审计权。

## 附：关键词速查

| 关键词 | 含义 |
|---|---|
| **Exit-Readiness** | 退出/并购准备（IPO、M&A、融资、剥离的合规性与成熟度） |
| **Strategy** | 中长期战略方向、业务布局、资源分配、重大转型 |
| **Strategy-Resolution Loop** | 战略-决议闭环（战略 → 议题 → 决策 → 行动项 → 责任人） |
| **Firm-wide Views** | 全公司视角/跨部门全局观点 |
| **Market Trends** | 外部宏观、竞争、政策等市场趋势 |
| **Commercial Trends** | 商业变现、定价、客户采购行为等趋势 |
| **Portable Trends Only** | 仅可复用/普适趋势，排除一次性现象 |
| **Live-deal Quarantined** | 在途交易信息严格隔离 |
| **Fundraising / Market / Multiples** | 融资 / 市场 / 估值倍数（P/E、P/S、EV/EBITDA） |
| **Confidentiality Filter** | 保密过滤，剔除机密与 NDA 限制内容 |
| **Commercial Buying Behavior** | 企业级采购决策链路与偏好 |
| **Software Usage** | 软件产品实际使用行为与反馈 |
