# 会议内容提取规则

**说明**： 该文档是基于AI已经识别参会人并将会议分类的前提下进行的。不同的会议类型产生的内容方向是不同的，所以分会议类型对内容进行提取总结加工

## 一、内容加工

### 去逐字化

会议分类完成后，读取原始转录，一次性输出所有派生内容；下游不再读取原文。

**核心保证：任何面向创始人的界面永不出现原文措辞。**

去逐字化双层保障：

1. **LLM 摘要层**：AI分析提取**会议摘要**，负责**非逐字表达**。（说法与原文不重复）
2. **机械式清洗层**：实体/人名剥离 + 与源转录的 **近逐字 n-gram 匹配**；一旦命中即剔除。**n-gram 阈值可调**，需实施期调优。

### **关键词解释补充：**

（1）

- **Exit-Readiness（退出/并购准备）：** 会议中涉及企业准备进行 IPO、被收购（M&A）、融资或业务剥离时的合规性、资产清晰度、运营成熟度及风险排查。AI 需要捕捉是否有讨论到“是否达到资本市场或投资人要求的规范标准”。
- **Strategy（战略）：** 中长期发展方向、核心业务布局、资源分配优先级及重大转型决策。

提炼出符合 资本运作、IPO/并购合规（Exit-Readiness）\标准的中长期\ **战略规划**。

（2）

- **Strategy-Resolution Loop（战略-决议闭环)** 会议中讨论出的“战略方向、待解决的问题（Issues）、最终决策（Decisions），以及后续的行动项（Action Items）和责任人”。AI 需要总结出哪些战略议题被推进了、达成了什么共识，以及下一步谁来跟进（形成闭环）。
- **Firm-wide Views（全公司视角/全局观点）：** 跨部门、跨业务线的全局性洞察与声音。AI 需要提炼出不同业务板块对该战略的反馈、整体组织层面的风险评估，或是对全公司有影响的高阶共识，而不是局限于某个单一团队的细枝末节。

让 AI 提炼出这场会议中“定下了什么全局战略、做出了哪些关键决议（含闭环追踪）”，以及反映出的“全公司/跨部门的宏观视角与共识”。

（3）

- **Market Trends（市场趋势）：** 外部宏观层面的变化。例如：行业新技术动向、用户需求偏好转变、竞争对手的动向、政策法规变化等。
- **Commercial Trends（商业/变现趋势）：** 业务与商业化层面的变化。例如：新的盈利模式、定价策略调整、渠道转化效率、客户采购行为的变化等。

让 AI 从会议中提取出与**外部行业风向、竞争态势、商业变现或客户采购偏好**相关的关键外部情报和洞察。

- **Portable Trends Only：** 仅提取**可复用/普适性**的趋势。排除局限于某一个特定客户、单一项目或一次性交易的临时现象，只保留对未来有长期参考价值、可在多业务或多场景间迁移复制的行业洞察。
- **Live-deal Quarantined：** **在途交易（正在谈的单子）信息隔离**。会议中涉及具体正在跟进、尚未落地的商业项目、谈判细节或竞争性投标数据，必须严格过滤或隔离，不得泄露或混入趋势总结中，以防合规风险或信息污染。

（4）

- **Fundraising（融资）：** 会议中关于引入外部投资、融资轮次、估值预期、向投资人展示的业务进展及资金使用计划的讨论。
- **Market（市场）**： 宏观市场环境、行业规模、竞争格局及外部需求变化。
- **Multiples（估值乘数 / 财务倍数）：** 资本市场或同类对标企业常用的估值指标（如市盈率 P/E、市销率 P/S、EV/EBITDA 等），用于评估公司估值或定价基准。
- **Confidentiality Filter（保密过滤）：** 数据过滤规则。要求 AI 在总结时自动剔除机密、敏感或受 NDA 限制的信息（如核心财务数据、未公开的客户名单、敏感条款等），确保输出内容安全合规。

提炼出适用于**融资路演和估值对标（Multiples）\**的市场/行业信息，并严格执行\**保密过滤（Confidentiality Filter）**，剔除机密数据。

(5)

- **Commercial Buying Behavior（商业采购行为）：** 企业级客户在购买、评估、决策软件及服务时的习惯与流程。例如：采购决策链条变长、更看重 ROI、对安全合规要求提高、倾向于集成化方案等。
- **Software Usage（软件使用情况）：** 终端用户或企业客户实际使用软件产品时的行为数据与反馈。例如：功能活跃度、高频使用场景、痛点、流失原因或对特定模块的依赖度。

提炼出客户在**企业采购决策模式**以及**实际软件产品使用偏好/习惯**方面的洞察。




## 三、管理员干预（Portfolio Group Manager / Super Admin）

**说明:** 
- 该功能实现页面为Fireflies Summary Records details页面，管理员可以对任何内容进行改判，改判后，最新内容和权限会实时更新到AI chatbot中，供用户查看/提问使用。
- 该功能包含AI未判定成功的会议的改判（状态为Pending的）

**可进行操作：**
- **改判会议类型** → 路由自动重算；
- **更改company** → 更改后下方内容将路由至新公司
- **更改content** → 更改后新的内容将会被应用
- **更改是否授权** → Authorize勾选框可决定前面的content是否授权给前面的角色
- **Start extraction按钮** → 点击该按钮，下方的提取和路由开始执行。按钮激活条件：pending的会议类型中AI Meeting Type和Company信息都有、Participants无未识别人，激活。其他会议类型（信息是全的），有改动时激活，若改动的信息不全面了则置灰。

**其他**
- **创始人转录访问约束**：创始人仅可看 **本人参加会议** 的完整转录；未参加会议只能通过 1a / Founder KB 摘要感知（即便与本公司相关）。
- 所有路由决策与覆盖动作 **写入审计日志**。
