# 题库草稿保存功能

## 原始需求：

题库并非一成不变的，而是会随时调整题目顺序和题目内容的。但是介于使用者不想改一个题就即时发布新题库（一般会在下个季度时发布新题库，省的发布了新的就要重新做）。

## 需求解读：

需要一个草稿保存功能以方便随时改但是可以统一发布。

## 功能：

### 功能更新

在 ERL Configuration 页面的 Publish 按钮旁边，新增一个 Save as Draft 按钮。

### 功能逻辑

#### 按钮激活规则

- 当用户对任一维度的题目顺序或内容进行修改后，Save as Draft 按钮即被激活。

- 保存草稿后：
  - 当前页面展示的内容即为最新草稿，草稿按钮置灰；

  - Publish 按钮变为激活状态，用户可随时提交发布。

- 若存在草稿，页面需展示提示文案，格式如下：

▎ Draft saved 【Time】by 【Name】

示例：

▎ Draft saved 4 Nov 2026, 06:59 (UTC) by GSV Assessment Team

#### 开发注意事项

1. 历史版本管理

- 用户查看当前使用的版本题库时，需点击 View History 按钮。
- 开发时需将当前已发布的版本也一并纳入历史记录中。

2. 保存/发布的作用范围

- Save as Draft 和 Publish 按钮的操作范围是所有维度，并非针对单一维度。
- 用户在修改过程中可自由切换各维度的 tab 进行编辑。
- 全部修改完成后，点击：
  - Save as Draft → 将所有维度的改动一并保存为新草稿；
  - Publish → 将所有维度的改动一并发布为新版本。
