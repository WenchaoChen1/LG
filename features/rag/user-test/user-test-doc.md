| # | 场景描述 | 操作步骤 | 预期结果 | 实际结果 | 通过 |

| 1 | 单文件超限（>50MB） | 上传一个 51MB 的 PDF | 上传前被拒（RAG_MAX_FILE_SIZE_MB=50），提示文件过大；后端返回 413 / `41301` | | ☐ |
